| Direct | Vague lifestyle fluff |

## Positioning frame (safe working hypothesis)

Zinc'd is a **US pool water-treatment technology brand** offering an engineered **Cu–Ag–Zn ionization** system for residential and commercial pools. Public messaging must remain within claims-register allowances. Residual chlorine of ~1.0 ppm remains part of responsible operation per technical documentation—never contradict this.

Arroyo is **never** mentioned publicly.

## Audience messaging differentiation

### B2B (distributors, builders, installers, commercial operators)

Emphasize:

- Operational value and reliability
- Installation fit with circulation systems
- Maintenance/support expectations
- Distribution / partnership opportunity
- Product sizing / series suitability (when models confirmed)
- Commercial and hospitality suitability
- Credibility via documented specs—not fake logos

Tone: professional, concise, equipment-category peer.

### B2C (homeowners, premium residential)

Emphasize:

- Clarity and comfort
- Understandable maintenance
- Simpler pool-management experience
- Guidance via assessment—not DIY complexity dumping
- Reduced chemical dependence **without** “chemical-free”

Tone: plain language, reassuring, non-patronizing.

## Message pillars (claims-aware)

| Pillar | Safe direction | Hard stop |
|---|---|---|
| Clearer water experience | Experiential, non-absolute | “Safe, non-irritating” absolute (C-008) |
| Lower chemical dependence | “Designed to reduce chlorine dependency” | “90% less,” “no chemicals needed” (C-004, C-005) |
| Engineered control | PWM control, monitoring, stainless build (`TS`) | Invented AI/smart claims |
| Algae / biofilm | “Helps control” (C-006 qualified) | “Eliminates” |
| Provenance | Historical silver-ion context only if used (C-003) | “NASA approved/technology” |
| Cost | “Can lower ongoing operating cost” qualitative only | Any $ monthly figures (C-010) |
| Proof | Specs + process honesty | Fake ratings, testimonials, military cases |

## CTA language

Do not use Buy Now / Shop Now / Order at launch.
